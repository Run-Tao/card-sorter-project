GUIDE

使用说明与验收路径

1. 启动

python -m pip install -r requirements.txt
python demo_app.py

浏览器打开 http://127.0.0.1:7860。模型首次加载约 3–8 秒，页面左上会显示状态。

2. 推荐演示流程

  1. 批次选择“两副无王（104 张）”，模型选 HOG+SVM。
  2. 关闭拒识（或保留阈值）点击“开始识别”，系统逐张执行真实推理。
  3. 观察中央预处理 6 步、右侧结果、底部 104 张牌组分布。
  4. 点击“注入重复牌”演示重复异常；点击“注入失败图”演示拒识/失败。
  5. 切换“模型实验”查看真实混淆矩阵；在“日志与导出”导出 CSV/JSON。

3. 批次说明

单副 54 / 两副 108 需要 Joker。当前没有 Joker 训练数据，因此批次中的 Joker 是明确标注的模拟事件，绝不冒充视觉识别结果。两副 104 无王模式完全由真实识别驱动。

4. 已实现 / 未实现

OpenCV 预处理模板 / HOG / CNN 拒识阈值批次/牌组校验 导出 CSV/JSON模拟演示 摄像头接口机械分拣/ESP32

机械分拣与 ESP32 未接入；界面保留控制状态与接口说明，不伪称已完成硬件控制。若电脑没有摄像头，点击“打开摄像头”会显示真实失败原因，图片/示例模式仍可完整演示。

5. 数据与限制

合成测试集 260 张（与训练同设计），真实照片 104 张（另一套牌设计、每类同一实体牌重复拍摄）。合成 98.85% 不代表真实牌 98.85%；真实照片 CNN 约 29.8%，说明跨设计域偏移严重。整机必须用团队自己的实体牌重新采集和验证。

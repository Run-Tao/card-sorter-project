# 后续完整计划（3 轮迭代后）

## 0. 当前基线（已完成，实际验证）

### Round 1：检测 + OOD
- 修复牌面检测：小面积插画候选不再轻易压过整张牌；增加纵向牌面先验。
- 新增模板相似度 OOD 门（阈值 0.55）：未见设计输出 `UNKNOWN`，不强行给 52 类。
- 实测 OOD（`outputs/ood_eval.md`）：
  - 合成同设计：OOD 误拒 **1.5%**（260 张）；
  - 真实另一套设计：OOD 拒识 **90.4%**（104 张）——符合预期，不再高置信度乱判。
- 三国杀 7♠：检测修正后角标可见；OOD=UNKNOWN（0.341），不再误报 JS/QD。

### Round 2：可纠正 / 可适配
- 单张图片支持**手动框选牌面**：自动检测失败时可拖框，裁剪后重新推理。
- 批次支持**人工修正标签**：把某条记录从错误标签/UNKNOWN 改为真实标签，同步更新批次计数；容量冲突会回滚。
- 新增**自定义模板登记**：OOD 时输入真实标签，把当前校正图登记为模板；同一设计以后可识别。
- 新增**决策树集成** `ensemble`：三模型候选 + 元特征 + 浅层树；低置信/低票拒识。
- 新增**两副牌两槽分离**：同标签第一次确认→A，第二次→B，第三次/UNKNOWN→复核；104 实测 A=52/B=52，108 实测 A=54/B=54。
- 实测三国杀 7♠：登记后 **7S / 1.000 / custom_match=True**。
- 测试：**35 个自动化测试通过**（新增 crop、correction、two-slot、ensemble 特征等）。

### Round 3：评估、回归、打包
- 新增 OOD 评估脚本 `tools/eval_ood.py` 与报告 `outputs/ood_eval.md`。
- 新增集成评估 `outputs/ensemble_eval.json`：合成 Top-1 100%，真实 Top-1 5.77%（接受准确率 40%）——集成不解决跨设计域偏移，保留作拒识/投票层。
- UI 全流程真实浏览器冒烟测试通过（开始/暂停/继续/停止/重置/模型实验/日志）。
- 批次真实 API 回归：`COMPLETE_104`、`COMPLETE_108`（4 模拟 Joker）、`COMPLETE_54`（2 模拟 Joker）、重复注入 `DUPLICATES_FOUND`；两槽计数 A/B 各 52/54。
- 打包：`card_sorter_final_system.zip`；`StartPokerSystem.exe` 轻量启动器（需本机 Python）。
- 未完成：完整独立 exe（PyInstaller + torch/Python 3.13 环境失败，未伪称）。

## 1. 最高优先级：目标域真实数据（下一周）

**目标**：把“能演示”变成“对本团队实体牌可用”。

1. 采 **2–3 副真实牌**（至少 2 个品牌/设计），每张实体牌多张照片：
   - 光照：正常/偏暗/偏亮；
   - 角度：0/90/180/270、轻微倾斜；
   - 距离/位置：工位固定 + 偏差；
   - 每张实体牌 ≥10–20 张。
2. 建立元数据 CSV：`card_id, brand, deck_id, label, physical_card_id, file, split`。
3. **按 physical_card_id 划分** train/val/test，禁止同一实体牌的近邻照片跨集合。
4. 先做 52 类普通牌；Joker 单独采集或继续只做批次标签。
5. 验收：真实测试集 Top-1、rank/suit、OOD 误拒/漏拒、检测成功率。

**没有这一步，不应继续调 CNN 上限。**

## 2. 角标识别分支（解决“任意牌面自动识别”）

当前对陌生设计的自动能力有限，OOD + 登记是实用折中。下一步：

1. 从目标域数据中裁 **rank/suit 角标**，训练轻量角标分类器（13 rank + 4 suit）；
2. 加入字体/背景/旋转/模糊增强；与整牌分类器融合：
   - 整牌高置信 → 采用；
   - 整牌 OOD 但角标高置信 → 角标结果 + 标记“角标模式”；
   - 两者冲突 → 拒识/复核；
3. 评估指标：角标 rank/suit 准确率、新设计零样本/少样本、OOD 误拒率；
4. 备选：Tesseract/EasyOCR 只做 rank OCR，suit 用形状分类；注意依赖与 exe 体积。

**验收**：对未登记的新设计，角标模式 Top-1 ≥ 80% 且冲突时能拒识；达不到就保留 OOD+登记，不硬上。

## 3. 预处理与 ROI 消融（第二周）

比较四种方案，用同一验证/测试集：

| 方案 | 说明 | 指标 |
|---|---|---|
| A 原图直接分类 | 不检测，整图 resize | 准确率、检测失败影响 |
| B 固定 ROI | 固定拍摄工位裁剪 | 准确率、鲁棒性 |
| C 自动四边形 | 当前检测+透视 | 检测率、准确率 |
| D 手动框选 | 当前新增兜底 | 失败样本恢复率 |

要求：
- 报告每种方案的 Top-1、检测成功率、耗时；
- 明确“固定 ROI 是否已够用”，不要默认复杂检测更好；
- 对检测失败样本单独统计，不混入总体准确率。

## 4. 模型与拒识（第二至三周）

1. 以真实数据重跑三模型公平对比：模板 / HOG+SVM / CNN；
2. CNN 优先做**微调**（冻结前层 / 小学习率），不要从头堆大模型；
3. 阈值在 val 上选，测试集只评估；报告覆盖率-接受准确率曲线；
4. OOD 门保留模板相似度 + 角标一致性；校准（temperature/isotonic）作为可选项；
5. 验收目标（按真实数据定，建议）：
   - 已确认牌准确率 ≥ 99%；
   - OOD/拒识可解释；
   - 单张 CPU 延迟 ≤ 100 ms（不含摄像头）。

## 9. 风险与应对

| 风险 | 应对 |
|---|---|
| 真实牌数据不足 | 先采 1 副、每类 10 张；用 OOD+登记完成演示，不吹泛化 |
| 角标 OCR 不稳 | 保留整牌分类 + OOD；角标只作辅助 |
| 卷积模型过拟合 | 冻结微调、强增强、按实体牌划分 |
| exe 打包失败 | 干净 venv、lite 版、便携运行时；不伪造 |
| 硬件卡牌/时序 | 先手动单张联调，加传感器与急停，再做连续 |

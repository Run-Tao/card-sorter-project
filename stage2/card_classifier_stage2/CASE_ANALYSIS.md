# 非训练集牌面识别问题：原因分析与改进

样例：用户上传的《三国杀》“兵临城下”牌，左上角印有 **7♠**，但不是标准扑克牌面；
画面有深色边框、中文标题、插画和复杂背景。

## 1. 实际测试（改进前）

用最终系统的三个模型直接识别，得到：

| 模型 | 预测 | 分数 | 说明 |
|---|---|---|---|
| 模板匹配 | 9D | 0.332 | 模板相似度很低，前两名差 0.016 |
| HOG+SVM | JS | 0.9997 | softmax 过度自信，完全错误 |
| CNN | QD | 0.465 | 错误 |

同时检查预处理发现：**牌面四边形检测选错了区域**——选到了牌面插画内部的一个小四边形，
透视校正结果是一块文字/插画，而不是整张牌。因此角标 7♠ 根本没有进入分类器。

## 2. 原因

1. **域偏移 / 未见设计**：训练集是 JackFurby 的同一套数字牌面（白底、简洁角标、
   标准花色布局）。三国杀牌是另一套设计：深色边框、中文标题、插画、纸张纹理。
2. **检测先验错误**：深色边框 + 低对比背景，导致外轮廓候选分数不高；内部插画块
   面积小、亮度高，反而得分更高。旧逻辑总是取最高分，于是裁到了插画。
3. **分类器过度自信**：HOG/CNN 是 52 类闭集分类器，对域外输入仍会输出 softmax
   （HOG 给了 JS 0.9997），分数不能直接当“可信度”。
4. **角标 ROI 依赖校正结果**：校正错则角标错；透视校正也不能解决所有方向/设计差异。
5. **模板匹配没有该设计模板**：相似度只有 0.33，但系统此前仍强行输出 52 类之一。

## 3. 已实现的改进

### 3.1 检测：大牌/纵向先验
`src/image_utils.py::detect_card_quad` 在候选评分中增加：
- 64% 以上画幅的候选轻微惩罚；
- 横向候选惩罚（标准牌应纵向）；
- 若最高分候选面积 <18%，而存在面积 18%–88% 的合理大牌候选且分数不低于最高分 80%，
  则选大牌候选。

在样例上，校正图从“插画文字块”变为包含完整牌面与 7♠ 角标的图像。
真实 104 张照片的检测率仍为 **96/104（92.3%）**，没有因该修改退化。

### 3.2 未知设计拒识（OOD）
每次推理同时计算模板相似度作为“设计是否见过”的检查：
- 模板相似度 < **0.55** 且不是已登记自定义模板 → `ood=True`；
- 输出 `UNKNOWN`，不把 HOG/CNN 的 52 类高分当结果；
- 记录 `design_similarity`、`design_label`、拒识原因；
- 界面显示“未见过的牌面设计”，并给出登记入口。

样例在改进后：HOG 的最优候选不再是最终标签，系统显示 **UNKNOWN / OOD**，
不再错误地宣称 JS。

### 3.3 自定义模板登记（针对新设计）
界面在 OOD 时提供“登记当前牌为新模板”：
1. 输入真实标签（如 `7S`）；
2. 后端把校正后的牌存为 `data/templates/7S_custom_*.png`；
3. 重新加载模板分类器；
4. 同一牌面设计以后可通过模板匹配识别，并在记录中标注
   `template_custom`，不计入 52 类通用模型准确率。

样例实测：

```text
登记前：UNKNOWN / OOD，模板相似度 0.341
登记后：7S，模板相似度 1.000，accepted=True，custom_match=True
```

这是“少量样本适配新牌面”的方案，不是“任意牌面零样本识别”。

### 3.4 批次/界面
- 批次开启“未知设计拒识”后，OOD 牌进入待确认，不会被算作已确认；
- 日志保留原图、校正图、双角 ROI、设计相似度和 OOD 原因；
- 单张/批次/摄像头路径都使用同一 OOD 判定。

## 4. 尚未解决

- 真正**零样本自动识别任意牌面**：当前用“角标语义兜底”读取 rank+花色，但要求角标存在且可读；
  无标准角标、严重遮挡/模糊的牌仍会拒识。
- 角标语义依赖 EasyOCR 和整牌模型的花色提示；EasyOCR 首次使用会下载模型，离线环境需预先缓存。
- 新设计若角标不可读，仍需要人工登记模板。
- 机械分拣仍未接入。

## 5. 使用方式

1. 打开界面 → “选择单张图片”上传新牌图片。
2. 若整牌模型判为陌生设计，系统自动走角标语义：OCR 点数 + HOG 花色，三国杀 7♠ 实测直接输出 **7S**。
3. 若角标也读不出，再输入真实标签（如 `7S`）→“登记当前牌为新模板”。
4. 整副新牌若角标可读，无需逐类登记；角标不可读时才逐类登记。

## 6. 结论

改进后系统不会再把三国杀牌“自信地”识别成 JS/QD；它会：
- 先判断整牌设计是否陌生；
- 陌生时走角标语义，读 rank + 花色得到 7S；
- 角标不可读时拒识或允许登记模板。

这解决了“不同牌面设计”的自动识别主路径，同时明确保留“无角标/不可读”的边界。
